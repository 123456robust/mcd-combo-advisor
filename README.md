# mcd-combo-advisor · 麦麦加班套餐助手

> 加班到十点，附近还能吃什么？
> 这是一个基于**麦当劳 MCP 能力**的套餐推荐 Skill —— 它回答的不是"麦当劳有什么"，而是"**此刻、此地、这个状态**下我该点什么"。

## 为什么做这个

榜单上大多数麦当劳项目都在做"省钱"和"套餐推荐"。但真实痛点出现在**非正常时段**：

- 22:40 下班，不知道附近门店还开不开
- 深夜想吃，又怕第二天体检报告难看
- 预算有限、两个人、现在这个点，怎么点最合适

这些问题靠一份静态菜单答不了，必须把**时间 + 地点 + 在售状态 + 热量 + 优惠券 + 实付价**一起算。

## 它怎么工作

7 个麦当劳 MCP 工具串成一条决策链（详见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)）：

```
now-time-info → query-nearby-stores → query-meals → query-meal-detail
                                          ↓
                        list-nutrition-foods → query-store-coupons → calculate-price
```

时段策略：

| 时段 | 策略 |
|---|---|
| 05:00–10:00 | 早餐组合 + 热饮 |
| 10:00–14:00 | 正餐份量，优先超值午餐 |
| 14:00–17:00 | 小食 + 饮料，控热量 |
| 17:00–21:00 | 正餐份量 |
| 21:00–23:00 | 偏轻负担，避免高油高钠 |
| 23:00–05:00 | 严格轻负担：>650 kcal 降级，咖啡因/碳酸标记不友好 |

## 安装

前置条件：已在 [https://mcp.mcd.cn](https://mcp.mcd.cn) 控制台激活并获取 **MCP Token**。

```bash
git clone https://github.com/123456robust/mcd-combo-advisor.git
cd mcd-combo-advisor

# 零第三方依赖，Python 3.9+ 直接跑
export MCD_MCP_TOKEN='你的Token'          # Windows: $env:MCD_MCP_TOKEN='你的Token'
python main.py --dump-tools
```

## 使用示例

```bash
python main.py --city "上海" --keyword "人民广场" --budget 40
```

- 经常加班、在非正餐时段点麦当劳的开发者与上班族

```

```

## 设计约束

- **不编造**：营业时间、在售餐品、价格全部以 MCP 实时返回为准；MCP 未返回的字段，明确提示以麦当劳官方渠道为准
- **不泄密**：Token 只从环境变量读取，仓库内不含任何真实凭据
- **降级不中断**：任一工具调用失败即跳过并标注，不影响整体推荐
